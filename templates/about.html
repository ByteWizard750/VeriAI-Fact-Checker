About Fake News Detector

Understanding how our AI-powered fake news detection system works

Project Overview

This Fake News Detector is an advanced machine learning system designed to identify potentially false or misleading news articles and statements using state-of-the-art natural language processing techniques.

The system combines multiple datasets and employs sophisticated algorithms to analyze text patterns, linguistic features, and content characteristics that are commonly associated with fake news versus legitimate journalism.

Datasets Used

  • News Dataset: 44,000+ articles from reliable and unreliable sources
  • LIAR Dataset: 12,800+ fact-checked statements from PolitiFact
  • Combined Training: Over 50,000 labeled examples

Machine Learning Models

  • Random Forest: Ensemble learning for robust predictions
  • XGBoost: Gradient boosting for high accuracy
  • Logistic Regression: Linear model for interpretability
  • LightGBM: Fast gradient boosting framework

How It Works

1. Text Input

User provides news article or statement

2. Preprocessing

Text cleaning, tokenization, and feature extraction

3. AI Analysis

Machine learning model processes features

4. Results

Prediction with confidence and explanations

SHAP Explainability

Our system uses SHAP (SHapley Additive exPlanations) to provide transparent explanations for each prediction. SHAP values help you understand:

  • Which words/features influenced the decision
  • How much each feature contributed
  • Whether features support "fake" or "true" classification
  • Visual representation of feature importance

Important Limitations

  • This tool is for educational and research purposes
  • Results should not be the sole basis for fact-checking
  • Always verify information through multiple reliable sources
  • Model performance may vary with different types of content

Technical Stack

  • Python: Core programming language
  • Flask: Web framework
  • Scikit-learn: Machine learning library
  • SHAP: Model explainability
  • NLTK: Natural language processing

Contributing to Media Literacy

This project aims to promote media literacy and critical thinking by providing tools to help users evaluate news content more effectively.

Remember: Technology is a tool to assist human judgment, not replace it. Always think critically and verify information through multiple trusted sources.
